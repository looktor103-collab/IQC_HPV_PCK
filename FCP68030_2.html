  1. เปิด Google Apps Script → สร้างโปรเจกต์ใหม่
  2. วาง code ด้านล่างนี้ใน Code.gs แล้ว บันทึก
  3. คลิก Deploy → New Deployment → Web App → ตั้ง "Execute as: Me" และ "Who has access: Anyone" → Deploy
  4. คัดลอก Web App URL มาใส่ในช่องด้านล่าง
